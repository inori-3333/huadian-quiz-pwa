# 华电刷题 PWA

基于当前 Android 版代码与题库的华电离线刷题网页应用，适配手机、iPad 和电脑。打开网页后可安装到主屏幕；各题库的错题、收藏、编辑内容与做题进度均独立保存在当前浏览器中。

## 在线使用

访问 **[华电刷题网页版](https://inori-3333.github.io/huadian-quiz-pwa/)**。

首次打开请保持联网，等待顶部显示“离线已就绪”。此时应用、6588 道题和两本安规原文已全部缓存，断网后也能重新打开和刷题。

在 iPad 上安装：

1. 用 Safari 打开应用。
2. 点工具栏中的“共享”。
3. 选择“添加到主屏幕”。

iPhone 的安装方式相同；Android、Windows 和 macOS 可使用 Chrome / Edge 打开网页，点击“安装应用”或浏览器菜单中的安装选项。也可以直接在浏览器中使用。

新版本下载完成后，点击“保存进度并更新”即可刷新，保留同一浏览器中的进度、收藏和手动修订。首次从旧版升级时，如仍显示旧题库，请关闭本站所有标签页和已安装应用后重新打开。

学习记录不上传服务器，也不会在设备、浏览器或 Android APK 之间自动同步。清除本站浏览器数据会删除本地学习记录。

## 功能

- 顺序、随机、指定题号与按题型练习
- 模拟安规考试：随机抽取 25 道单选（每题 1 分）、20 道填空（每题 2 分）、20 道判断（每题 1 分），共 65 题、85 分
- 考试答题卡支持跳题和修改答案，自动保存未完成考试；交卷后展示总分、各题型得分和本次错题回顾（含你的答案、正确答案与匹配的安规原文）
- 五个独立题库，可随时切换且进度互不混合
- “待巩固”与“历史错题”双分组：最近一次做对会移出待巩固，历史错题永久保留
- 错题重刷、收藏和单题错误次数统计
- 全文搜索、章节筛选与题目手动修订
- 答错后自动显示最匹配的 2024 版安规原文、条款号与来源（知识竞赛题库除外）
- 刷题时右滑回看上一道已答题，左滑或点击“返回当前题”继续；历史回看中的正确题也显示匹配的安规原文，正常答对自动切题时不显示
- 滑动说明仅在首次打开首页时弹出，关闭后永久记住；刷题页不显示上一题按钮或滑动提示
- 自动保存未完成练习，随时继续
- 适配 iPad 横屏/竖屏、安全区与触控热区
- 标准 Web App Manifest、Service Worker 和主屏幕图标
- 明确的离线缓存状态、安装指引与保存进度后更新
- 完全离线运行，不请求任何第三方资源

## 模拟考试

用户先选择题库，再从该题库主页进入“模拟安规考试”。组卷仅使用当前题库，考试页不再选择题库，也不会跨题库补题。目前“安规考试 8.28”和“第2周安规考试题库”题型齐全，可独立组卷；2024 版通用、燃煤题库缺少填空题，考试页会提示当前题库无法组成完整试卷。每次试卷内不重复抽题，不设置考试时限。填空题沿用题库答案匹配规则，整题正确得 2 分，不拆空给分；未答题得 0 分并计入错题。每个题库在当前浏览器中保留最近一次考试，重新组卷会替换该题库上次考试的成绩和回顾，累计错题记录仍保留。

## 本地预览与测试

需要 Node.js 22+ 与 Python 3，无需安装第三方依赖：

```bash
npm run build
npm test
npm run preview
```

然后访问 `http://localhost:8080`，预览与 Pages 相同的构建产物。Service Worker 只会在 HTTPS 或 localhost 环境下启用。

如需直接预览源文件：

```bash
npm run dev
```

源文件预览的缓存版本是固定的；修改代码后请使用生产构建预览，或在浏览器开发工具中停用该开发站点的 Service Worker。

## 部署

`.github/workflows/pages.yml` 在 `main` 分支更新后自动部署，也支持手动运行。仓库的 Pages 来源设为 **GitHub Actions**。

发布流程会重新从 `app/assets/data/` 嵌入最新题库和安规数据，构建 `dist/`，运行题库、判题和离线缓存检查，全部通过后再上传到 Pages。缓存版本根据资源内容自动生成；所有路径均相对于项目目录，可部署在 `/huadian-quiz-pwa/` 子路径下。

## 项目结构

- `app/`：PWA 界面、离线缓存、图标和内置题库
- `dist/`：自动生成的 Pages 发布目录，不提交到 Git
- `tests/`：题库完整性、判题逻辑和 PWA 配置检查
- `android-app/`、`native-src/`：保留的 Android 离线包工程
- `scripts/`：题库解析、嵌入与 Android 构建脚本

## 更新安规检索来源

两本安规以只读检索数据导入，不会出现在题库列表中。更新来源文件时执行：

```bash
python scripts/parse_safety_regulations.py --general "通用要求.docx" --coal "燃煤发电.docx"
python scripts/embed_banks.py
```
